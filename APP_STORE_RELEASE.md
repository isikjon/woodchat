## 2. Что нужно получить до отправки

1. **Платный аккаунт Apple Developer** (99 $/год) — https://developer.apple.com/programs/
2. Решить, **как распространять** (см. §3).
3. Подготовить: почту поддержки, ссылку на политику конфиденциальности (обязательна), скриншоты (см. §6).

## 3. Важно: способ распространения

WoodChat — **внутренний корпоративный мессенджер**. Apple по правилу 4.2.1 регулярно отклоняет такие приложения из публичного App Store с формулировкой «приложение предназначено для сотрудников — используйте частную раздачу».

Варианты:

**А. Частная раздача через Apple Business Manager (рекомендуется).**
Приложение проходит упрощённую проверку и доступно только сотрудникам компании по ссылке. Нужен Apple Business Manager (бесплатно) + аккаунт разработчика организации (нужен D-U-N-S номер компании).

**Б. Публичный App Store.**
Возможен, если позиционировать как приложение для клиентов компании (общение с менеджерами, лента новостей), а не как внутренний инструмент. Тогда обязательно: демо-аккаунт для проверяющего, публичное описание, политика конфиденциальности.

**В. TestFlight (в любом случае первый шаг).**
До 100 внутренних тестировщиков без проверки Apple, до 10 000 внешних — с быстрой проверкой. Для запуска внутри компании этого часто достаточно.

## 4. Сборка архива (пошагово)

1. Открыть проект: `open StreamChatSwiftUI.xcodeproj`
2. В списке схем сверху выбрать **WoodChat**, устройство — **Any iOS Device (arm64)**.
3. Выбрать таргет **DemoAppSwiftUI** → вкладка **Signing & Capabilities** → в поле **Team** выбрать команду организации (не Personal Team).
4. Проверить **Bundle Identifier**: `com.isikjandev.woodchat` (или ваш, если занят).
5. Меню **Product → Archive**. Сборка займёт несколько минут.
6. В открывшемся окне Organizer нажать **Distribute App** → **TestFlight & App Store** → **Upload**.
7. Дальше — в App Store Connect: заполнить карточку (§5), добавить тестировщиков в TestFlight.

Проверить сборку из терминала можно так:

```bash
xcodebuild -scheme WoodChat -project StreamChatSwiftUI.xcodeproj -configuration Release -destination 'generic/platform=iOS' archive -archivePath ~/Desktop/WoodChat.xcarchive
```

## 8. Пуш-уведомления — ВКЛЮЧЕНЫ

Настроены 17.08.2026 по ключу APNs заказчика (Key ID 9A9WQKL28K, Team ID Q5CPN332XB).

**Что сделано:**
- Ключ `.p8` лежит только на сервере: `/var/www/wood/data/www/stream-gateway/secrets/` (права 600, в git не попадает).
- Настройки в `.env` шлюза: `APNS_KEY_PATH`, `APNS_KEY_ID`, `APNS_TEAM_ID`, `APNS_TOPIC`, `APNS_ENVIRONMENT`.
- Шлюз: эндпоинты `POST/GET/DELETE /devices` (регистрация устройства из SDK), отправка через APNs HTTP/2 с JWT ES256, автоотключение мёртвых токенов.
- Пуш уходит участникам беседы, которых нет онлайн (нет открытого WebSocket), кроме самого отправителя. Бейдж — суммарное число непрочитанного.
- Приложение: `aps-environment = development`, запрос разрешения при входе, регистрация токена через `addDevice(.apn)`.

**Проверено:** Apple принимает ключ и подпись (на выдуманный токен отвечает `BadDeviceToken`, а не отказом в авторизации); сквозной путь сообщение → пуш → очистка мёртвого токена отработал на проде.

**ВАЖНО при переходе на TestFlight/App Store:**
1. В `DemoAppSwiftUI/DemoAppSwiftUI.entitlements` заменить `development` на `production`.
2. На сервере в `/var/www/wood/data/www/stream-gateway/.env` поставить `APNS_ENVIRONMENT=production` и перезапустить шлюз.
Если этого не сделать — пуши на сборки из TestFlight приходить не будут (`BadDeviceToken`).

**Расширение уведомлений (App Groups)** пока не подключено — нужно только для показа картинок в пуше и точного бейджа в фоне. Текст, звук и переход в нужный чат работают без него.

## 10. Если Apple отклонит

Самые вероятные причины и что отвечать:

**«Приложение для внутреннего использования» (4.2.1)** → перейти на частную раздачу через Apple Business Manager либо объяснить, что приложение предназначено для клиентов компании: лента новостей и общение с менеджерами доступны любому клиенту Woodstream.

**«Нет удаления аккаунта» (5.1.1v)** → указать путь: значок профиля → «Профиль и аккаунт» → «Удалить аккаунт».

**«Нет механизма жалоб на контент» (1.2)** → в приложении есть блокировка пользователей и жалоба на сообщение (долгое нажатие на сообщение), жалобы уходят администратору.

**«Не работает демо-аккаунт»** → проверить, что учётная запись активна, и что сервер доступен снаружи.
